# Sample project idea (the vague starting point)

This is the kind of message that SpecSprint is built for. It is deliberately loose.

> I keep losing track of what I spend. I want something simple where I can note down expenses and see how much I've spent. Maybe with categories? It should be quick to use, I don't want to open a big app.

What is missing: who else uses it, where the data lives, what "see how much" means, whether editing is needed, which platform, and what counts as done.

Feed this to an agent that has the spec-sprint skill installed. The files next to this one show what a good result looks like:

- [sample-spec.md](sample-spec.md) is the specification.
- [sample-plan.md](sample-plan.md) is the task plan.
- [expense-tracker/](expense-tracker/) is the small program that came out of following the plan.
- [sample-verification-report.md](sample-verification-report.md) is the report in the format ProofBuild produces.
